# skill-expose-builder

Exposé-Builder: Querformat-Verkaufsexposé als PDF.

## Installation (automatische Updates)
In Claude Code:

    /plugin marketplace add andre-petrov-creator/skill-expose-builder
    /plugin install expose-builder@skill-expose-builder

Danach unter `/plugin` → Marketplaces → `skill-expose-builder` das **Auto-Update einschalten**.

Dieses Repo ist ein automatisch erzeugter Spiegel. Änderungen nur im Quell-Repo.
